# Instrucciones para Claude

Lee y cumple [`AGENTS.md`](AGENTS.md) antes de analizar, modificar o ejecutar el
proyecto. `AGENTS.md` es la única fuente de verdad operativa para todos los
agentes; este archivo existe sólo como punto de entrada compatible con Claude.

Después aplica, según el cambio:

- [`docs/sdd/`](docs/sdd/README.md) para comportamiento y aceptación.
- [`docs/architecture.md`](docs/architecture.md) para límites entre módulos.
- [`docs/data-model.md`](docs/data-model.md) para persistencia y compatibilidad.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) para contribuciones públicas.

No copies reglas nuevas aquí. Actualiza `AGENTS.md` o el documento canónico que
corresponda para evitar instrucciones divergentes.
