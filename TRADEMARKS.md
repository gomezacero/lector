# Nombre e identidad de Lector

La licencia GPL-3.0 se aplica al código y no concede derechos sobre nombres,
logotipos o elementos que identifiquen una versión como oficial.

Puedes mencionar Lector para describir honestamente el origen del software,
enlazar el proyecto, informar compatibilidad o indicar que una versión deriva de
él. También puedes redistribuir copias oficiales sin modificar conservando su
nombre y avisos.

Una versión modificada no debe presentarse como publicada, aprobada o respaldada
por Lector o `gomezacero`. Los forks con cambios sustanciales deben usar un nombre
y una identidad visual distintos, y pueden indicar de forma secundaria que
derivan de Lector.

Esta política no afirma que exista una marca registrada ni limita usos
permitidos por la ley aplicable. Para solicitar una excepción, contacta mediante
el perfil de GitHub [`@gomezacero`](https://github.com/gomezacero).
