# Seguridad

## Versiones compatibles

Mientras Lector permanezca en la serie `0.x`, sólo la versión publicada más
reciente recibe correcciones de seguridad.

## Informar una vulnerabilidad

No publiques detalles explotables ni PDF con información privada en una
incidencia pública. Usa el reporte privado de vulnerabilidades del repositorio
en GitHub cuando esté habilitado. Si todavía no aparece, contacta primero al
mantenedor mediante [`@gomezacero`](https://github.com/gomezacero) para acordar
un canal privado.

Incluye versión, sistema operativo, impacto, pasos mínimos para reproducir y un
fixture sintético cuando sea posible. Nunca envíes documentos personales.
